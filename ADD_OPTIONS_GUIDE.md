# 📝 Руководство по добавлению новых опций и цен

## ✨ Новая функция: Динамическое управление опциями

Теперь вы можете добавлять, редактировать и удалять опции прямо через веб-интерфейс без изменения кода!

---

## 🎯 Как добавить новую опцию

### Шаг 1: Откройте раздел "Цены"
1. Перейдите на http://localhost:3000
2. Нажмите на вкладку **"💲 Цены"** в верхней панели

### Шаг 2: Выберите категорию
Вы можете добавлять опции в любую из категорий:
- **Модель купели** (Shell Models)
- **Тип дерева** (Wood Types)
- **Цвет оболочки** (Shell Colors)
- **Тип крышки** (Lid Types)
- **Цвет дерева** (Wood Colors)
- **Особенности** (Features)

### Шаг 3: Нажмите "Добавить опцию"
В нужной категории найдите и нажмите кнопку **"➕ Добавить опцию"**

### Шаг 4: Заполните форму
Откроется диалоговое окно с тремя полями:

1. **Ключ опции** (обязательно):
   - Уникальный идентификатор на английском
   - Используйте только маленькие буквы, цифры и подчеркивания
   - Примеры: `premium_model`, `custom_color_1`, `extra_large`
   - ❗ Пробелы автоматически заменяются на подчеркивания

2. **Название опции** (обязательно):
   - Название, которое будет видно пользователям
   - Можно на русском или польском языке
   - Примеры: `Премиум модель XXL`, `Пользовательский цвет`, `Экстра большая`

3. **Цена (€)** (обязательно):
   - Цена опции в евро
   - Можно использовать дробные числа (например: 1500.50)
   - Примеры: `5000`, `250.00`, `1850`

### Шаг 5: Добавьте опцию
1. Нажмите кнопку **"➕ Добавить"**
2. Появится уведомление об успешном добавлении
3. Новая опция появится в списке с меткой **(пользовательская)**

### Шаг 6: Сохраните изменения
1. Прокрутите страницу вниз
2. Нажмите кнопку **"💾 Обновить цены"**
3. Появится уведомление **"Цены успешно сохранены!"**
4. ✅ Готово! Новая опция сохранена в базу данных

---

## 🔄 Использование новых опций в калькуляторе

### Автоматическая синхронизация
После сохранения цен новые опции автоматически появляются в калькуляторе:

1. Перейдите на вкладку **"📐 Калькулятор"**
2. Откройте соответствующий выпадающий список (например, "Модель купели")
3. 🎉 Ваша новая опция появится в списке с ценой!

### Пример
Если вы добавили:
- Ключ: `premium_xxl`
- Название: `Премиум XXL модель`
- Цена: `5000`

В калькуляторе она появится как:
```
premium xxl +5000€
```

## ✏️ Редактирование существующих опций

### Изменение цены
1. Откройте раздел **"Цены"**
2. Найдите нужную опцию
3. Измените значение в поле цены
4. Нажмите **"Обновить цены"** внизу страницы

### ℹ️ Примечания
- Стандартные опции имеют переводы (отображаются на русском/польском)
- Пользовательские опции отображаются как введены
- Изменения цен применяются мгновенно в калькуляторе

---

## 🗑️ Удаление опций

### Как удалить опцию
1. Откройте раздел **"Цены"**
2. Найдите опцию, которую хотите удалить
3. Нажмите на иконку **🗑️ корзины** справа от опции
4. Подтвердите удаление в диалоге
5. Опция будет удалена из списка
6. Нажмите **"Обновить цены"** для сохранения

### ⚠️ Важно!
- Удаленные опции исчезнут из калькулятора
- Если опция используется в существующих заказах, они сохранят старые значения
- Удаление необратимо после сохранения цен

## 💡 Советы и рекомендации

### ✅ Лучшие практики
- **Используйте понятные ключи**: `premium_model` вместо `pm1`
- **Добавляйте описательные названия**: "Премиум модель XXL" вместо "Модель 1"
- **Проверяйте цены**: Убедитесь что цена корректна перед сохранением
- **Сохраняйте сразу**: После добавления нескольких опций нажмите "Обновить цены"

### ⚠️ Чего избегать
- ❌ Не используйте пробелы в ключах (они будут заменены на _)
- ❌ Не используйте спецсимволы (#, %, &, @) в ключах
- ❌ Не создавайте дубликаты ключей в одной категории
- ❌ Не удаляйте опции, которые активно используются

### 🔧 Устранение проблем

**Опция не появляется в калькуляторе?**
1. Убедитесь что нажали "Обновить цены"
2. Переключитесь на другую вкладку и обратно на "Калькулятор"
3. Обновите страницу в браузере (F5)

**Ошибка при сохранении?**
1. Проверьте что все поля заполнены
2. Проверьте что ключ уникален
3. Проверьте логи backend: `sudo supervisorctl tail backend stderr`

**Цена не рассчитывается?**
1. Убедитесь что цена сохранена (есть уведомление)
2. Проверьте что опция выбрана в калькуляторе
3. Посмотрите в "Итог заказа" справа

## 🎓 Дополнительная информация

### Как работает система
1. **Pricing Page** → Добавляете/редактируете опции
2. **Backend API** → Сохраняет в MongoDB
3. **Calculator Page** → Загружает актуальные опции
4. **Order Summary** → Рассчитывает итоговую стоимость

### Структура данных
```json
{
  "shellModels": {
    "round200": 1500,
    "premium_xxl": 5000
  },
  "features": {
    "jacuzzi": 800,
    "custom_option": 500
  }
}
```

### Локализация
Стандартные опции переводятся автоматически:
- `round200` → "Круглая 200 см" (RU) / "Okrągła 200 cm" (PL)

Пользовательские опции отображаются как есть:
- `premium_xxl` → "premium xxl" (в обоих языках)

Для добавления переводов пользовательских опций:
1. Откройте `/app/frontend/src/i18n/locales/ru.json`
2. Добавьте: `"premium_xxl": "Премиум XXL модель"`
3. Повторите для `/app/frontend/src/i18n/locales/pl.json`
4. Перезапустите frontend: `sudo supervisorctl restart frontend`
