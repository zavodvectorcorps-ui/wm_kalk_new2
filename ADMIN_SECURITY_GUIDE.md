## 🎯 Работа в режиме администратора

### Индикаторы авторизации

После успешного входа вы увидите:
- **Бейдж "Админ"** в правом верхнем углу header
- **Кнопку выхода** (иконка LogOut) рядом с бейджем
- **Иконку замка** на вкладке "Цены" исчезнет

### Доступные действия

В режиме администратора вы можете:
- ✅ Просматривать все цены
- ✅ Редактировать существующие цены
- ✅ Добавлять новые опции (через кнопку "Добавить опцию")
- ✅ Удалять опции (через иконку корзины)
- ✅ Сохранять изменения
- ✅ Свободно переключаться между всеми вкладками

### Навигация

После входа вы можете:
- Переходить на вкладку "Калькулятор" - без ограничений
- Переходить на вкладку "Заказы" - без ограничений
- Возвращаться на вкладку "Цены" - **без повторного ввода пароля**

Ваша сессия сохраняется до выхода или закрытия вкладки браузера.

## ⚠️ Безопасность

### Что защищено

- **Страница цен**: Требует пароль для доступа
- **Редактирование цен**: Доступно только после входа
- **Добавление опций**: Доступно только после входа
- **Удаление опций**: Доступно только после входа

### Что НЕ защищено

- **Калькулятор**: Доступен всем пользователям
- **Заказы**: Доступны всем пользователям (просмотр и создание)
- **Переключение языков**: Доступно всем

### Хранение сессии

- **SessionStorage**: Сессия сохраняется в sessionStorage браузера
- **Действует до**: Закрытия вкладки или выхода из системы
- **Не сохраняется**: При обновлении страницы сессия сохраняется

**Что делать:**

2. Введите заново
3. Нажмите "Войти"

### Отмена входа

**Кнопка "Отмена":**
- Закрывает модальное окно
- Очищает поле пароля
- Остается на текущей странице (Калькулятор или Заказы)

## 🔧 Технические детали

### Реализация

**Компоненты:**
- `/app/frontend/src/components/AdminLogin.jsx` - Модальное окно входа
- `/app/frontend/src/App.js` - Логика авторизации
- `/app/frontend/src/components/Header.jsx` - Индикаторы статуса

**Хранение:**
- `sessionStorage.getItem('adminAuth')` - Статус авторизации
- Очищается при закрытии вкладки или выходе

**Пароль:**
- Хранится в константе `ADMIN_PASSWORD` в `AdminLogin.jsx`
- Проверка происходит на фронтенде
- Для изменения пароля отредактируйте файл `AdminLogin.jsx`

### Изменение пароля

1. Откройте файл: `/app/frontend/src/components/AdminLogin.jsx`

2. Найдите строку:
```javascript
const ADMIN_PASSWORD = '159357';
```

3. Измените на новый пароль:
```javascript
const ADMIN_PASSWORD = 'ваш_новый_пароль';
```

4. Сохраните файл

5. Перезапустите frontend:
```bash
sudo supervisorctl restart frontend
```

## 📊 FAQ

### Вопрос: Можно ли использовать несколько паролей?

**Ответ:** Сейчас поддерживается один пароль. Для добавления нескольких паролей нужно доработать код.

### Вопрос: Безопасна ли эта защита?

**Ответ:** Это базовая защита на фронтенде. Для production рекомендуется:
- Перенести проверку пароля на backend
- Использовать JWT токены
- Добавить HTTPS
- Добавить rate limiting

### Вопрос: Что делать если забыл пароль?

**Ответ:** 
1. Посмотрите в этом файле (пароль: 159357)
2. Или в коде: `/app/frontend/src/components/AdminLogin.jsx`
3. Или спросите у разработчика

### Вопрос: Можно ли защитить другие страницы?

**Ответ:** Да, аналогичным образом можно защитить "Заказы" или любую другую страницу. Нужно добавить проверку в `App.js`.

### Вопрос: Сессия сохраняется при обновлении страницы?

**Ответ:** Да, при обновлении страницы (F5) сессия сохраняется. Она удаляется только при:
- Нажатии кнопки выхода
- Закрытии вкладки браузера
- Очистке sessionStorage
