# Инструкция по установке виджета WM Kalkulator для amoCRM

## Файлы виджета

Виджет находится в папке `/app/amocrm-widget/` и включает:
- `manifest.json` — описание виджета
- `script.js` — логика виджета  
- `style.css` — стили
- `images/` — папка для иконок (можно добавить logo.png)

Архив для загрузки: `/app/amocrm-widget.zip`

---

## Шаг 1: Создание интеграции в amoCRM

1. Войдите в amoCRM → **Настройки** → **Интеграции**
2. Нажмите **"Создать интеграцию"** (или откройте существующую)
3. В разделе **"Виджеты"** нажмите **"Загрузить виджет"**
4. Выберите архив `amocrm-widget.zip`

---

## Шаг 2: Настройка виджета

После загрузки виджета укажите настройки:

- **URL API**: `https://wm-kalkulator.pl/api`
- **URL приложения**: `https://wm-kalkulator.pl`

---

## Шаг 3: Включение виджета

1. Перейдите в **Настройки** → **Интеграции**
2. Найдите виджет **"WM Kalkulator"**
3. Включите его для нужных воронок

---

## Функционал виджета

### 1. Виджет в карточке сделки
При открытии карточки сделки показывает:
- **Статус доставки** (Ожидает / В пути / Доставлен)
- **Информация о рейсе** (название, водитель, дата)
- **Кнопка просмотра фото акта** (если загружено)

Виджет автоматически ищет заказ по ID сделки в системе логистики.

### 2. Виджет в боковой панели
Отображает кнопки для открытия калькулятора:
- 🛁 **Купель** — открывает калькулятор купелей
- 🔥 **Сауна** — открывает калькулятор саун
- 🌿 **Теплица** — открывает калькулятор теплиц

При нажатии калькулятор открывается во всплывающем окне с данными сделки.

## API Endpoints

Виджет использует следующие API endpoints:

### GET /api/widget/delivery-status/{lead_id}
Получить статус доставки по ID сделки amoCRM.

**Ответ:**
```json
{
  "found": true,
  "orderId": "AMO-GH-12345",
  "section": "greenhouse",
  "status": {
    "code": "delivered",
    "label": "Доставлен",
    "color": "#22c55e"
  },
  "trip": {
    "id": "GH-123",
    "name": "Рейс 15 января",
    "driverName": "Иван",
    "departureDate": "2025-01-15"
  },
  "delivery": {
    "confirmedAt": "2025-01-15T14:30:00Z",
    "receivedAmount": "5000 PLN",
    "photo": { "hasPhoto": true }
  }
}
```

### GET /api/widget/delivery-photo/{lead_id}
Получить фото акта доставки.

### GET /api/widget/calculator-url?lead_id={id}&calculator={type}
Получить URL для открытия калькулятора.

## Требования

- amoCRM: версия 2.0+
- Браузер: Chrome, Firefox, Safari, Edge
- Доступ к API: необходим HTTPS

---

## Устранение неполадок

### Виджет не показывает данные
1. Проверьте, что заказ создан из amoCRM (через webhook)
2. Проверьте URL API в настройках виджета
3. Откройте консоль браузера (F12) для просмотра ошибок

### Калькулятор не открывается
1. Разрешите всплывающие окна для amoCRM
2. Проверьте URL приложения в настройках

### CORS ошибки
Убедитесь, что на сервере настроен CORS для домена `*.amocrm.ru`
