# Калькулятор Купели с Джакузи / Hot Tub Calculator

Профессиональный калькулятор для создания заказов на купели с джакузи с двуязычной поддержкой (русский/польский) и генерацией PDF.

## 🎯 Основные возможности

### ✅ Калькулятор заказов
- **Информация о клиенте**: Полное имя, телефон, адрес, дата заказа
- **Конфигурация купели**:
  - Модели: Круглые (200см, 225см) и Квадратные (170x200, 220x220, 230x230, 245x245)
  - Типы дерева: Ель, Термо, WPC, Красный кедр
  - Цвета оболочки: 15 вариантов (белый, жемчужные оттенки, с блестками)
  - Типы крышки: Стекловолоконная, СПА
  - Цвета дерева: Акрилас (7 вариантов мрамора), натуральный, окрашенный, масляный

### 🎨 Особенности и дополнения
- Джакузи
- Воздушные пузыри
- LED освещение (наружное/внутреннее, полосы, мини)
- Изоляция
- Подушка для головы
- Песочные фильтры (3 варианта)
- Нагреватели (V4A, электрический 3кВт)
- Электрический щит
- Удлинитель дымохода
- Защита дымохода
- Bluetooth радио
- Электрический термометр

### 📊 Управление
- **Список заказов**: Просмотр всех заказов с возможностью скачивания PDF
- **Управление ценами**: Редактирование цен для всех опций
- **Двуязычность**: Переключение между русским и польским языками
- **Генерация PDF**: 
  - Клиентский вариант (современный, готовый к печати)
  - Технический вариант (для производства с подробными данными)

## 🔧 API Endpoints

### Цены
- `GET /api/prices` - Получить текущие цены
- `POST /api/prices` - Обновить цены

### Заказы
- `GET /api/orders` - Получить все заказы
- `POST /api/orders` - Создать новый заказ

### PDF
- `POST /api/generate-pdf` - Сгенерировать PDF (customer или technical)

## 💾 База данных

### Коллекции MongoDB
1. **prices**: Хранение цен для всех опций
   - `shellModels`: Цены на модели
   - `woodTypes`: Цены на типы дерева
   - `shellColors`: Цены на цвета
   - `lidTypes`: Цены на крышки
   - `woodColors`: Цены на цвета дерева
   - `features`: Цены на дополнительные функции

2. **orders**: Хранение заказов
   - Информация о клиенте
   - Выбранная конфигурация
   - Выбранные функции
   - Общая сумма
   - Дата создания

## 🌐 Использование

### Калькулятор
1. Заполните информацию о клиенте
2. Выберите конфигурацию купели
3. Отметьте необходимые функции
4. Добавьте примечания (опционально)
5. Просмотрите итоговую сумму справа
6. Сохраните заказ или сгенерируйте PDF

### Управление ценами
1. Перейдите на вкладку "Цены"
2. Отредактируйте необходимые цены
3. Нажмите "Обновить цены"

### Просмотр заказов
1. Перейдите на вкладку "Заказы"
2. Просмотрите список всех заказов
3. Скачайте PDF (клиентский или технический)
