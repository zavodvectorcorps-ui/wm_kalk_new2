## 🔧 Тестирование Backend через API

### Метод 1: Через curl (командная строка)

```bash
# 1. Проверка работы API
curl http://localhost:8001/api/

# Ответ: {"message":"Hot Tub Calculator API"}

# 2. Получить текущие цены
curl http://localhost:8001/api/prices

# Ответ: JSON со всеми ценами

# 3. Получить список заказов
curl http://localhost:8001/api/orders

# Ответ: [] (пустой массив если заказов нет)

# 4. Обновить цены (POST запрос)
curl -X POST http://localhost:8001/api/prices \\
  -H "Content-Type: application/json" \\
  -d '{
    "shellModels": {
      "round200": 1600,
      "round225": 1900
    },
    "woodTypes": {
      "spruce": 0,
      "thermo": 350
    },
    "shellColors": {},
    "lidTypes": {},
    "woodColors": {},
    "features": {}
  }'

# 5. Создать тестовый заказ
curl -X POST http://localhost:8001/api/orders \\
  -H "Content-Type: application/json" \\
  -d '{
    "fullName": "Иван Петров",
    "phoneNumber": "+48 123 456 789",
    "fullAddress": "Варшава, ул. Главная 123",
    "orderDate": "2025-01-15",
    "shellModel": "round200",
    "woodType": "thermo",
    "shellColor": "white",
    "lidType": "glassFiberLid",
    "woodColor": "natural",
    "sandFilter": "none",
    "features": {
      "jacuzzi": true,
      "airBubble": true
    },
    "notes": "Тестовый заказ",
    "total": 3200.00
  }'
```

### Метод 2: Через MongoDB напрямую

```bash
# Подключиться к MongoDB
mongosh

# Использовать базу данных
use hottub_calculator

# Посмотреть цены
db.prices.findOne()

# Посмотреть все заказы
db.orders.find().pretty()

# Обновить конкретную цену
db.prices.updateOne(
  { "_id": "default" },
  { $set: { "shellModels.round200": 1700 } }
)

# Удалить тестовый заказ
db.orders.deleteOne({ "fullName": "Иван Петров" })

# Удалить все заказы (осторожно!)
db.orders.deleteMany({})
```

### Метод 3: Через Python скрипт

Создайте файл `test_backend.py`:

```python
import requests
import json

BASE_URL = "http://localhost:8001/api"

# 1. Тест получения цен
print("1. Получение цен...")
response = requests.get(f"{BASE_URL}/prices")
print(f"Статус: {response.status_code}")
print(f"Цены: {json.dumps(response.json(), indent=2, ensure_ascii=False)}")

# 2. Тест обновления цен
print("\\n2. Обновление цен...")
new_prices = {
    "shellModels": {
        "round200": 1650,
        "round225": 1950,
        "square170x200": 1700,
        "square220x220": 2100,
        "square230x230": 2300,
        "square245x245": 2600
    },
    "woodTypes": {"spruce": 0, "thermo": 320, "wpc": 420, "redCedric": 520},
    "shellColors": {"white": 0, "ivory": 55, "blue": 55},
    "lidTypes": {"glassFiberLid": 210, "spaLid": 310},
    "woodColors": {"natural": 0, "painted": 160, "oiled": 210},
    "features": {"jacuzzi": 850, "airBubble": 650}
}

response = requests.post(f"{BASE_URL}/prices", json=new_prices)
print(f"Статус: {response.status_code}")
print(f"Результат: {response.json()}")

# 3. Тест создания заказа
print("\\n3. Создание заказа...")
order = {
    "fullName": "Анна Ковальская",
    "phoneNumber": "+48 987 654 321",
    "fullAddress": "Краков, ул. Цветочная 45",
    "orderDate": "2025-01-20",
    "shellModel": "round225",
    "woodType": "thermo",
    "shellColor": "blue",
    "lidType": "spaLid",
    "woodColor": "oiled",
    "sandFilter": "sandFilterBox",
    "features": {
        "jacuzzi": True,
        "insulation": True,
        "outsideLed12": True
    },
    "notes": "Доставка в субботу",
    "total": 3500.00
}

response = requests.post(f"{BASE_URL}/orders", json=order)
print(f"Статус: {response.status_code}")
print(f"Заказ создан: {json.dumps(response.json(), indent=2, ensure_ascii=False)}")

# 4. Тест получения заказов
print("\\n4. Получение всех заказов...")
response = requests.get(f"{BASE_URL}/orders")
print(f"Статус: {response.status_code}")
print(f"Количество заказов: {len(response.json())}")
print(f"Заказы: {json.dumps(response.json(), indent=2, ensure_ascii=False)}")
```

Запустите:
```bash
python test_backend.py
```

## 🎯 Полное тестирование через интерфейс

### Шаг 1: Тест калькулятора

1. Откройте http://localhost:3000
2. Заполните информацию о клиенте:
   - Имя: "Тест Тестов"
   - Телефон: "+48 111 222 333"
   - Адрес: "Тестовый адрес 1"
   - Дата: выберите текущую дату

3. Выберите конфигурацию:
   - Модель: Круглая 200 см
   - Тип дерева: Термо
   - Цвет оболочки: Белый
   - Тип крышки: Стекловолоконная
   - Цвет дерева: Натуральный

4. Выберите опции:
   - Песочный фильтр: Песочный фильтр под лестницей
   - Отметьте: Джакузи, Воздушные пузыри, Изоляция

5. Проверьте итоговую сумму справа
   - Должна автоматически обновиться

6. Нажмите **"Сохранить заказ"**
   - Должно появиться уведомление об успехе

7. Нажмите **"Создать PDF"**
   - Должен скачаться PDF файл

### Шаг 2: Тест просмотра заказов

1. Нажмите на вкладку **"📋 Заказы"**
2. Вы должны увидеть созданный заказ в таблице
3. Нажмите **"Скачать PDF"** - скачается клиентская версия
4. Нажмите **"Скачать технический"** - скачается версия для производства

### Шаг 3: Тест управления ценами

1. Нажмите на вкладку **"💲 Цены"**
2. Измените несколько цен:
   - Круглая 200 см: с 1500€ на 1550€
   - Джакузи: с 800€ на 850€
3. Прокрутите вниз и нажмите **"Обновить цены"**
4. Вернитесь на вкладку **"Калькулятор"**
5. Выберите измененные опции
6. Проверьте, что цены обновились в итоговой сумме

### Шаг 4: Тест смены языка

1. Нажмите на кнопку **"🌐 RU"** в правом верхнем углу
2. Язык должен переключиться на польский (PL)
3. Все тексты должны измениться
4. Нажмите снова - вернется русский

## 🐛 Решение проблем

### Если цены не обновляются:
```bash
# Перезапустить backend
sudo supervisorctl restart backend

# Проверить MongoDB
sudo supervisorctl status mongodb

# Очистить кеш браузера и перезагрузить страницу
```

### Если PDF не генерируется:
```bash
# Проверить backend логи
sudo supervisorctl tail backend stderr

# Убедиться что reportlab установлен
pip list | grep reportlab
```

### Если frontend не загружается:
```bash
# Перезапустить frontend
sudo supervisorctl restart frontend

# Проверить логи
sudo supervisorctl tail frontend stderr
```
